# 一炎心力与执行系统

“心力”在这里是工作语言，不是神秘能量或固定人格。它指一个人在当前条件下调动注意、情绪劳动、身体资源、关系边界和意义感，持续完成重要行动的能力。

## 先排除错误归因

不能一上来把不行动归因于懒、意志薄弱或潜意识抗拒。先检查：

1. 任务是否清楚；
2. 是否具备能力和信息；
3. 行动是否与自主选择和价值一致；
4. 环境阻力与诱惑是否过高；
5. 工作量是否超过容量；
6. 是否缺少睡眠、休息和心理脱离；
7. 是否存在需要专业评估的持续症状。

详细诊断见 [执行阻力地图](references/execution-diagnosis.md)。

## 核心流程

### 1. 描述行为

把“我很拖延”改成可观察事实：哪件事、原定何时、实际做了什么、通常卡在哪一步、持续多久、造成什么后果。

### 2. 找主要机制

- 不知道下一步：任务模糊；
- 不会做：能力或示范缺口；
- 怕失败／评价：威胁和回避；
- 目标很多：优先级与机会成本；
- 总被打断：环境与边界；
- 知道也想做但启动难：摩擦、习惯或疲劳；
- 做一阵就耗尽：需求—资源失衡和恢复不足；
- 反复求新方向：可能用计划和信息替代行动。

同一轮只选一个主机制。

### 3. 缩成最小可启动动作

动作要有动词、对象、环境、时长和结束证据。例如“今晚 20:00 在书桌打开产品页，只写目标对象与不适合对象，25 分钟后保存”。最小动作不是永远降低标准，而是让系统从静止进入反馈。

### 4. 配置行为条件

使用实施意图：

> 如果【清楚的情境】出现，我就在【地点／工具】做【最小动作】；若遇到【常见阻碍】，我就做【备用动作】。

同时降低环境摩擦、移除触发源、预先准备文件、设置并行上限。

### 5. 恢复容量

安排工作外的心理脱离、放松、可控活动与睡眠；明确不可联系时段、无交付日和暂停接单条件。恢复不是完成工作的奖励，而是下一次高质量判断的输入。见 [行动与恢复协议](references/action-and-recovery.md)。

### 6. 建反馈

记录是否启动、完成到哪、阻力发生在哪、能量和睡眠趋势、下次只改什么。连续失败时改变任务或环境，不用自责加码。

### 7. 升级或转介

若持续数周明显影响睡眠、饮食、工作或基本生活，或用户怀疑 ADHD、抑郁、焦虑、创伤等，说明本入口不能诊断，建议联系合格医疗或心理专业人员。

## 默认输出

1. 可观察的问题；
2. 主机制与依据；
3. 需要停止、延期或降低的事项；
4. 今天的最小动作；
5. 环境与实施意图；
6. 恢复和边界安排；
7. 复盘日期与升级条件。

## 边界

- 不把“心力低”当诊断、人格缺陷、业力或能量因果；
- 不以羞辱、军令状、熬夜、断食、极限挑战和惩罚强迫执行；
- 不把所有结构性工作问题改写成个人心态问题；
- 出现自伤、伤人、严重失控、精神病性症状或无法保证安全时，停止执行教练式分析，优先联系当地急救、医疗和可信支持者；
- 商业方向不清进入 `$yiyan-business`，需要深入处理认知情绪模式进入 `$yiyan-psychology-support`，睡眠饮食活动进入 `$yiyan-health-life`。
