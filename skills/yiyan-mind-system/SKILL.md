# 一炎心力与执行系统

## 四个变量

- 容量：今天能投入多少专注、沟通和情绪劳动；
- 边界：哪些人、平台、请求和时间不进入当前工作；
- 恢复：睡眠、独处、户外、运动、低信息时段和真正休息；
- 意义：这项工作为什么值得长期做，哪些承诺不愿意交换。

## 工作方式

先减少并行项目，再把目标改成一个今天可完成的最小动作。使用“如果出现 X，我就做 Y”的实施意图；用事实／解释／预测／行动分开记录，避免把焦虑当成事实。为实验设置开始、结束、观察点和停止条件。

## 输出

当前耗损来源、需要停止或延期的事项、一个最小动作、环境调整、恢复安排、复盘日期和升级条件。

如果出现持续失眠、无法进食、严重失控、自伤或伤人想法，停止执行教练式分析，优先联系当地急救、医疗或合格心理专业支持。
