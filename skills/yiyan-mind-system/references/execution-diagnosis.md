# 执行阻力地图

## 一、六个判断维度

### 1. 任务

- 完成标准是否可见；
- 下一步是否小到能开始；
- 是否混合了多个决定；
- 任务是否真的必要。

### 2. 能力

- 是否知道怎样做；
- 是否有示范、工具和反馈；
- 自我效能感低是否来自缺少练习证据；
- 任务难度是否应分级。

### 3. 动机

- 是用户自己的选择，还是外部压力；
- 与什么价值和长期身份一致；
- 即时成本是否远大于延迟收益；
- 是否存在真实两难，而不是“不够想要”。

### 4. 环境

- 文件、工具和空间是否准备好；
- 干扰和诱惑怎样触发；
- 是否有人或规则不断打断；
- 能否通过默认选项和预承诺减少摩擦。

### 5. 容量

- 同时承担多少项目；
- 任务需要多少注意、沟通和情绪劳动；
- 睡眠、身体、照顾责任和财务压力如何影响；
- 工作要求是否超过资源。

### 6. 恢复

- 下班后能否心理脱离；
- 是否有放松、掌控感和非工作活动；
- 是否长期在休息时处理消息；
- 是否用刷信息代替真正恢复。

## 二、常见维持循环

### 完美主义

高标准且含糊 → 启动成本高 → 回避 → 时间变少 → 质量下降 → 更自责 → 进一步抬高标准。

打断点：定义“可交付版本”、限制修改轮次、先完成后评估。

### 信息焦虑

不确定 → 搜索更多 → 选择变多 → 更难决定 → 继续搜索。

打断点：先写决策需要的三个事实、搜索上限和决定日期。

### 项目过多

每个项目都重要 → 不愿放弃 → 频繁切换 → 都没有反馈 → 觉得方向不对 → 再开新项目。

打断点：一个主项目、一个维持项目、其余进入有复评日期的停车场。

### 恢复不足

高要求 → 延长工作 → 睡眠和脱离减少 → 判断与情绪资源下降 → 工作更慢 → 继续延长。

打断点：先减少负荷和在制工作，恢复不能只靠周末补偿。

## 四、停止条件

连续两个周期没有改善时，不继续把动作切得更碎。重新检查任务价值、能力缺口、环境、健康和是否需要专业评估。
