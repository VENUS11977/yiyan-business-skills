# 商业模型与经济约束

## 一、商业闭环

### 客户与情境

不要只写年龄、性别和职业。写清楚谁在什么时刻发现旧办法不够用，当前怎样处理，付出了什么时间、金钱、风险或情绪代价。

### 价值主张

价值是客户在特定情境中感受到的进展，不等于你的知识总量。写清：

- 客户可以带走的可观察结果；
- 哪些结果由你负责；
- 哪些需要客户参与；
- 哪些受外部条件影响，无法保证。

### 获客与信任

列出客户在哪里出现、以什么问题搜索、谁能介绍、为什么相信。流量只是看见；证据、适配和风险降低决定是否购买。

### 交付与结束

列出付款前、交付中、交付后各步骤，注明客户行动、前台体验、后台工作、质量标准、异常和结束条件。

### 收入与成本

分开记录：

- 一次性收入、订阅、复购、转介绍和其他收入；
- 固定成本、变动成本、支付／平台费用、退款、税费；
- 获客、沟通、准备、交付、售后、管理和恢复工时。

## 二、基本经济公式

`单笔贡献毛利 = 单价 - 单笔直接变动成本`

`盈亏平衡单量 = 周期固定成本 ÷ 单笔贡献毛利`

`有效时薪 = 周期可支配收入 ÷ 周期实际投入总工时`

`获客成本 = 获客费用与可计量获客工时成本 ÷ 新客户数`

这些是经营口径，不是会计或税务意见。口径要固定，并说明退款、税费和创作者工资怎样处理。

## 三、现金流检查

利润为正也可能资金链紧张。检查：

- 什么时候收钱，什么时候支出；
- 是否需要先购买库存、广告、设备或外包；
- 客户退款和平台结算周期；
- 淡旺季、续费和应收款；
- 个人生活储备是否与经营资金分开。

早期项目优先缩短“投入到获得可靠反馈”的周期。

## 四、轻资产过滤器

每项写证据，不只打分：

| 维度 | 问题 |
|---|---|
| 固定成本 | 没有订单时仍必须支付什么 |
| 库存与设备 | 能否先预售、租用、按需采购或使用已有工具 |
| 反馈周期 | 7～30 天能看到哪种真实行为 |
| 失败可逆 | 停止后是否留下债务、合同、声誉或健康损害 |
| 获客可达 | 是否能低成本接触第一批目标客户 |
| 交付能力 | 当前能否完成承诺，最危险的能力缺口是什么 |
| 单位经济 | 一单是否产生合理贡献毛利和有效时薪 |
| 合规伦理 | 是否必须夸大、隐瞒、制造依赖或越界才能成交 |
| 生活适配 | 长期节奏是否与健康、关系和价值一致 |

出现高额不可逆投入、交付能力缺口或伦理红线时，不能靠“市场很大”抵消。

## 五、增长顺序

1. 验证问题真实存在；
2. 验证有人愿意采取行动或付费；
3. 验证产品能稳定交付；
4. 验证单位经济可接受；
5. 验证获客可以重复；
6. 再考虑自动化、团队、广告和多产品扩张。

每一层都保留反证。一次成交证明“至少一次成立”，不证明可复制。
