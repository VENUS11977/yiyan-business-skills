# 一炎商业与轻资产创业

轻资产不是“完全不花钱”，也不是某个行业标签。它是一组约束：固定成本较低、投入可分段、反馈周期较短、失败可以停止、关键能力在自己可控范围内，并且能用真实交易逐步验证。

## 先判断任务模式

- **方向探索**：不知道做什么，比较多个机会；
- **业务诊断**：已经在做，想找增长或亏损的真正瓶颈；
- **重大选择**：全职／副业、转型、合作、扩张或停止；
- **商业模型**：需要把客户、价值、渠道、收入、成本和交付串成闭环。

用户只说“推荐项目”时，不先给项目清单。先盘点手段、可承受损失、接触得到的人群和能交付的结果。

## 核心流程

### 1. 定义现实目标

确认想改变的经营状态、时间跨度和最低成功标准。区分收入目标、现金流目标、学习目标、影响力目标和生活方式目标；它们会导向不同业务。

### 2. 建立事实底板

把信息分为：

- 已发生事实与数据；
- 用户经验和能力证据；
- 外部研究与客户证据；
- 个人解释、直觉或象征；
- 尚未验证的假设。

没有交易时不把“粉丝喜欢”当需求；有收入时也不自动把一次偶然成交当作可重复模式。

### 3. 盘点可用手段

按“我是谁、我知道什么、我认识谁、我能接触谁”盘点技能、信誉、内容、渠道、关系、工具、时间、资金和健康容量。这里使用效应逻辑、资源基础观与创业拼凑，详见 [战略与创业理论](references/strategy-and-entrepreneurship.md)。

### 4. 画商业闭环

至少写清：目标对象、触发场景、待推进的进展、当前替代方案、价值主张、获客入口、信任证据、付款方式、交付过程、售后、关键资源、成本和风险。详见 [商业模型与经济约束](references/business-model-and-economics.md)。

### 5. 找当前约束

从需求、产品、信任、获客、成交、交付、容量、现金流和合规中只找一个主约束。当前约束没有改善前，不同时重做定位、产品、平台和团队。

### 6. 比较方向

至少比较两个候选和“暂不做”。使用五个标准：

1. 问题强度与发生频率；
2. 可接触客户和现有信任；
3. 交付能力与学习距离；
4. 单位经济和现金流；
5. 可逆性、伦理与生活适配。

评分只用于暴露假设，不替代判断。

### 7. 设计可逆实验

每个实验写清：假设、对象、动作、时间上限、资金上限、交付上限、证据、成功阈值、继续条件和停止条件。测试顺序通常是问题 → 付费意愿 → 交付结果 → 可重复获客 → 扩张。

### 8. 作出阶段决定

给出继续、调整、暂停或停止中的一个建议，并说明依据和下一次复评条件。实验模板与三种场景见 [实验与工作表](references/experiments-and-worksheets.md)。

## 一炎体系的转译

可以使用“一炎四步转译”：

`视角或直觉 → 可核对事实 → 最小行动 → 复盘证据`

五元素经营盘和乾卦阶段只能作为用户自有的观察语言，不能证明市场因果。若使用，必须同步给出现实指标和可推翻判断的信号。

## 默认输出

1. 当前阶段与主约束；
2. 关键事实、推断和未知；
3. 商业闭环或候选比较；
4. 最小实验；
5. 单位经济与现金流风险；
6. 继续、调整、暂停或停止条件；
7. 今天能完成的一步。

## 边界

- 不保证收入、融资、流量或成功率；
- 不鼓励借高息债、押上全部资产、囤积大量库存或先承担长期固定成本；
- 不虚构市场规模、竞争数据、客户访谈和付费意愿；
- 需要精确行业数据、法律、税务、投资或平台规则时，核对当前官方来源；
- 产品范围与定价进入 `$yiyan-product-design`，内容进入 `$yiyan-content-system`，运营进入 `$yiyan-business-operations`；
- 碰到危险健康状态、心理危机或违法规避时停止商业优化。
