# 一炎个人品牌、私域与销售

品牌是他人在多次接触后形成的稳定预期；销售是双方判断是否值得进入交易的过程。目标不是说服所有人，而是让适配者降低真实不确定性，也让不适配者安全退出。

## 先判断瓶颈

- **看不懂**：定位、主页或产品语言模糊；
- **不相信**：缺少相关证据、过程透明和一致体验；
- **不适配**：内容吸引的人与产品服务的人不同；
- **不行动**：下一步复杂、风险不清或时机不对；
- **不成交**：价值、价格、范围、决策参与者或替代方案有问题；
- **成交后失望**：承诺与交付不一致；
- **复购不健康**：靠旧焦虑和依赖维持关系。

先解决一个主瓶颈，不同时重写定位、主页、话术和价格。

## 核心流程

### 1. 定义品牌承诺

写清“帮助谁，在什么情境下，用什么方式，推进什么变化”，再写“不服务谁、不承诺什么、为什么可信”。定位是资源取舍，不是把所有能力塞进一句话。

### 2. 建立证据地图

证据按相关性与强度排序：

1. 作品与现场演示；
2. 可解释的方法与过程；
3. 匿名、授权、有限的客户案例；
4. 持续交付数据与复盘；
5. 专业训练、资质与经历；
6. 第三方评价和转介绍。

粉丝量、财富展示和昂贵包装只能是弱线索，不能替代与承诺相关的证据。详细方法见 [定位、品牌与证据](references/positioning-and-evidence.md)。

### 3. 设计接触点

从第一次刷到内容，到主页、置顶、产品页、私信、预约、付款、交付、售后和转介绍，逐点写清用户问题、所需信息、风险、证据和下一步。

### 4. 私信与销售会谈

先确认情境、事实、期望结果、已尝试办法、决策约束和适配性；再复述理解、说明范围、给选择、处理异议。禁止先诊断、后制造恐惧，再把购买包装成唯一解法。会谈模板见 [销售与客户旅程](references/sales-and-journey.md)。

### 5. 处理异议

区分：

- 信息缺口：补范围、流程、证据；
- 价值不清：回到客户任务和替代成本；
- 风险顾虑：说明隐私、退款、边界和不保证；
- 时机不对：允许延期或结束；
- 不适配：拒绝或转介；
- 价格超出预算：提供范围不同的真实选项，不临时贬值核心服务。

### 6. 跟进与关系

跟进必须带来新信息或帮助判断，不用连续催促。复购应对应新阶段、新任务或更高能力；转介绍依赖价值可被复述、入口清楚和隐私安全。

### 7. 复盘

同时观察有效线索、适配率、成交率、成交周期、退款、投诉、交付结果、复购原因、转介绍和销售工时。成交率越高不一定越好，可能代表筛选不足或承诺过宽。

## 默认输出

1. 当前信任／成交瓶颈；
2. 定位与边界；
3. 品牌证据地图；
4. 客户旅程和接触点；
5. 私信／会谈／异议脚本；
6. 指标与实验；
7. 不适配与拒绝条件。

## 边界

- 可以不露脸、分组可见、使用品牌名或保护职业隐私；不能伪造职业、学历、收入、客户、资质和第三方身份；
- 不使用恐惧、羞耻、诅咒、虚假倒计时、假名额、假评价和“先制造依赖再复购”；
- 不擅自公开客户聊天、订单、照片、身份和可重识别案例；
- 不承诺购买后必然成功，也不把拒绝购买解释成认知低或不够勇敢；
- 产品不清时转 `$yiyan-product-design`，交付失控时转 `$yiyan-business-operations`。
