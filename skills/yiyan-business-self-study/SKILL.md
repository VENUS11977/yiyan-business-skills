# 一炎商业与自媒体总入口

帮助用户在 10 个独立入口中选择一个主入口。本 Skill 只做分流，不直接完成商业诊断、写内容、心理支持、佛学解释或健康计划。

## 入口目录

| Skill | 分类入口 | 适合解决的问题 |
|---|---|---|
| `$yiyan-business` | 商业与轻资产创业 | 商业模式、创业方向、现金流、机会筛选与小实验 |
| `$yiyan-product-design` | 产品与服务设计 | 定位、目标人群、产品阶梯、定价逻辑、交付边界 |
| `$yiyan-content-system` | 自媒体与内容系统 | 抖音、小红书、视频号、选题、脚本、直播与内容复盘 |
| `$yiyan-brand-sales` | 个人品牌、私域与销售 | 主页、信任证据、私信筛选、成交、客户分层与转介绍 |
| `$yiyan-business-operations` | 交付、运营与经营看板 | SOP、售前售后、容量、有效时薪、复购、退款与复盘 |
| `$yiyan-mind-system` | 心力与执行系统 | 拖延、过载、信息焦虑、边界、恢复与可持续节奏 |
| `$yiyan-psychology-support` | 心理学辅助 | 事实／解释／担忧／行动的教育性拆分，不做诊断或治疗 |
| `$yiyan-buddhism-support` | 佛学辅助 | 正命、因缘、无常、执著、慈悲与经营伦理的辅助思考 |
| `$yiyan-health-life` | 健康生活 | 睡眠、饮食、活动、环境和恢复对长期经营的支持 |

## 已描述需求时

一次只推荐一个主入口：

- “怎么赚钱、要不要创业、轻资产项目、业务很乱” → `$yiyan-business`；
- “卖什么、服务谁、怎么定价、课程／咨询怎么设计” → `$yiyan-product-design`；
- “抖音、小红书、视频号、短视频、直播、文案、选题” → `$yiyan-content-system`；
- “主页、私域、私信、成交、复购、客户筛选” → `$yiyan-brand-sales`；
- “交付混乱、售后、流程、时间不够、数据复盘” → `$yiyan-business-operations`；
- “拖延、没心气、信息过载、无法坚持” → `$yiyan-mind-system`；
- “焦虑、灾难化、认知偏差、情绪调节” → `$yiyan-psychology-support`；
- “佛法、执著、正命、发心、因果如何看经营” → `$yiyan-buddhism-support`；
- “减重、饮食、睡眠、运动、身体状态” → `$yiyan-health-life`。

如果问题同时涉及多个方向，按用户现在最想改变的状态选择一个主入口；只有不同入口会改变结果时，问一个问题：

> 你现在最想先得到的是商业判断、内容方案，还是解决自己的执行状态？

## 输出

给出推荐 Skill、推荐理由和一条可直接复制的调用提示词。必要时说明另一个入口何时再用。输出后停止，不代替入选 Skill 执行任务。

## 边界

- 不把佛学、心理学、健康或象征语言当成收入的确定因果；
- 不推荐任何入口来替代医疗、心理治疗、法律、税务或投资专业意见；
- 不读取或暴露客户私密案例；
- 用户明确选择入口后，应由对应 Skill 完成主体任务。
