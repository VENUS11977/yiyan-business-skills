# 一炎商业与自媒体系统总入口

这不是九个互不相干的聊天模板。整个体系把轻资产经营看成一个连续系统：

`战略选择 → 产品与价值 → 内容与需求 → 信任与成交 → 交付与学习`

心力、心理学、佛学与健康生活是经营者的支持层。它们可以改变行动设计、伦理边界和长期产能，不能替代客户证据、现金流、合同、平台规则或专业医疗。

## 使用方式

用户没有指定入口时，先展示入口菜单；用户已经描述问题时，直接推荐一个主入口，不要求他先理解体系。用户明确选择入口后，停止分流，由对应 Skill 工作。

| 调用 | 入口 | 主要问题 | 典型交付 |
|---|---|---|---|
| `$yiyan-business` | 商业与轻资产创业 | 做什么、值不值得做、怎样低风险验证 | 机会判断、商业模型、实验卡、现金流边界 |
| `$yiyan-product-design` | 产品与服务设计 | 卖什么、服务谁、怎样定价与交付 | 客户任务、产品一页纸、服务蓝图、价格实验 |
| `$yiyan-content-system` | 自媒体与内容系统 | 讲什么、怎样长期生产、数据怎么看 | 内容战略、栏目、选题、脚本、发布与复盘系统 |
| `$yiyan-brand-sales` | 个人品牌、私域与销售 | 怎样被理解、被信任、筛选并成交 | 定位、证据地图、客户旅程、销售会谈与跟进 |
| `$yiyan-business-operations` | 交付、运营与经营看板 | 业务已经在跑但混乱、耗时或不赚钱 | SOP、容量模型、单位经济、质量与复盘看板 |
| `$yiyan-mind-system` | 心力与执行系统 | 知道要做却启动不了、项目过多、长期耗竭 | 阻力诊断、最小动作、边界、节奏和恢复协议 |
| `$yiyan-psychology-support` | 心理学辅助 | 认知、情绪、回避、两难怎样影响行动 | 非临床问题建模、行为实验、价值与应对计划 |
| `$yiyan-buddhism-support` | 佛学辅助 | 正命、执著、因缘、无常怎样帮助反思 | 教义分层、伦理审视、条件图、修习与行动问题 |
| `$yiyan-health-life` | 健康生活 | 睡眠、饮食、活动和工作方式怎样支撑经营 | 低风险生活调整、7 天基线、工作恢复计划 |

## 自动判断

一次只推荐一个主入口。用用户此刻最需要的“交付物”判断，不按关键词机械匹配。

1. 还没有方向，或在几个方向之间摇摆：`$yiyan-business`。
2. 方向大致确定，但产品、对象、成果或价格说不清：`$yiyan-product-design`。
3. 产品已经存在，缺少稳定选题、表达或传播系统：`$yiyan-content-system`。
4. 有内容和询问，但定位、信任、私信筛选或成交有问题：`$yiyan-brand-sales`。
5. 已有订单，但交付、售后、工时、利润或复购失控：`$yiyan-business-operations`。
6. 方案其实清楚，主要卡在启动、坚持、过载或边界：`$yiyan-mind-system`。
7. 用户要理解想法、情绪、回避或选择冲突：`$yiyan-psychology-support`。
8. 用户明确要从佛法教义、修学或经营伦理反思：`$yiyan-buddhism-support`。
9. 主要问题是睡眠、饮食、活动、久坐或恢复：`$yiyan-health-life`。

若仍无法区分，只问一个会改变入口的问题：

> 你这次最想带走的是商业方向、一个能卖的产品、内容方案、成交路径、运营系统，还是先恢复行动与生活状态？

## 阶段路径

- **零起点**：商业 → 产品 → 内容／品牌销售 → 运营。
- **有能力但没产品**：产品 → 商业验证 → 内容。
- **有账号但不变现**：产品 → 品牌销售；只有产品已清楚时才先做内容。
- **有客户但太累**：运营 → 产品范围；不要先扩大流量。
- **反复换方向**：商业判断；若答案已知而持续回避，再使用心力或心理学。
- **价值冲突或职业伦理困惑**：商业事实先行，需要时加入佛学辅助。
- **状态长期不稳**：健康与心力优先；明显症状或安全风险转介专业支持。

更完整的体系关系见 [系统地图](references/system-map.md)；想按自身阶段安排连续学习时读取 [学习路径](references/learning-paths.md)。不要在普通分流时默认加载两个参考文件。

## 分流输出

只输出：

1. 推荐入口；
2. 为什么是它；
3. 当前问题中哪些是事实、哪些仍待确认；
4. 一条可直接复制的调用提示词；
5. 另一个入口要在什么条件下再使用。

## 总边界

- 商业为主轴，佛学、心理学、心力与健康是支持层，不构成赚钱的神秘因果。
- 不承诺收入、流量、爆款、成交、疗愈、改命或任何确定结果。
- 不把个人经验、课程观点、经典教义、心理学研究和经营假设混成同一种证据。
- 不替代医疗、心理治疗、法律、税务、投资、劳动或平台合规意见。
- 用户明确选定入口后停止，不在总入口里做一个缩水版答案。
