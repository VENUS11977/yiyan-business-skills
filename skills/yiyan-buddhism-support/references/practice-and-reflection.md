# 修习与反思

这些练习只用于一般佛学教育和日常反思，不代替正式禅修指导、心理治疗或医疗。若练习引起明显恐惧、解离、失眠、创伤回忆或精神状态恶化，应停止并寻求合适支持。

## 一、停一息再行动

在发布、成交、争执或重大决定前：

1. 暂停，不急于强化当下冲动；
2. 观察身体感受、情绪、念头和行动冲动；
3. 分辨事实、解释与欲望；
4. 问这项行动会增加还是减少伤害、欺骗、依赖和后悔；
5. 选择一个符合现实责任的动作。

它是日常正念提示，不等同于完整的四念处或禅修教授。

## 二、因缘条件图

```
当前结果：
已经具备的条件：
缺失的条件：
我能影响的条件：
暂时不能控制的条件：
我的意图：
我的身语意行动：
哪些行动会增加善的条件：
哪些行动会增加伤害与执取：
何时重新观察：
```

条件图用于减少单因果和宿命解释。若问题涉及市场、合同、疾病或安全，必须同步取得相应现实证据。

## 三、正命复盘

每周选择一次交易或内容：

- 我实际承诺了什么；
- 有没有夸大、隐瞒或利用焦虑；
- 客户是否有知情和退出权；
- 我是否把对方当成实现收入的工具；
- 这笔收入要求我反复做什么样的人；
- 哪个环节更符合正语、正业和正命；
- 下次具体修改哪一句话或哪一步。

## 四、无常复盘

观察一项正在变化的业务、关系或身份：

1. 哪些条件已经变化；
2. 我仍试图固定什么；
3. 坚持来自证据、价值，还是害怕失去身份；
4. 哪个部分应继续；
5. 哪个部分应调整或结束；
6. 结束后仍能保留什么善的能力和关系。

无常不要求频繁放弃。它要求按变化更新，而不是把旧承诺当永恒。

## 五、无住与发心

分两栏：

| 容易黏着的对象 | 不黏着后仍愿意做的善行 |
|---|---|
| 收入数字 | 诚实核算、负责交付 |
| 粉丝和名声 | 提供真实、有用内容 |
| “成功者”身份 | 接受反馈和停止失效项目 |
| 被客户需要 | 帮助客户恢复自主 |
| “慈悲的人”形象 | 设边界、拒绝不适配服务 |

无住不能成为回避经营责任的理由。发心要落在身语意行动与现实后果中。

## 六、布施检查

布施前问：

- 是否自愿；
- 是否在自己能力范围内；
- 是否尊重接受者；
- 是否附带操控、回报或公开羞辱；
- 是否会损害家庭、健康和基本责任；
- 金钱、时间、知识、空间和善意哪种形式更合适；
- 接受者是否真的需要这一形式。

布施不能被承诺为确定换取财富、消灾或商业成功的交易。

## 七、善友与纠偏

为经营与修学分别建立可信支持：

- 能提醒戒与边界的人；
- 能指出市场、财务和专业问题的人；
- 能在情绪高涨或低落时提供现实观察的人；
- 不利用宗教身份要求服从或付费的人。

同一个人未必同时具备宗教、商业、心理和医疗专业能力。不同问题使用不同支持系统。
