# 测量与内容实验

## 一、指标必须对应任务

| 阶段 | 可观察指标 | 常见误读 |
|---|---|---|
| 触达 | 展现、搜索曝光、独立观众 | 把触达当信任 |
| 注意 | 开头留存、停留、完播／读完 | 只用刺激提高停留 |
| 理解 | 收藏、正确复述、有效评论 | 收藏不一定使用 |
| 信任 | 主页访问、案例阅读、重复观看 | 粉丝数不等于适配 |
| 行动 | 资料领取、私信、预约、试用 | 私信多不等于购买 |
| 交易 | 有效线索、成交、客单、退款 | 成交不等于利润 |
| 交付 | 完成、结果、投诉、售后工时 | 忽略交付成本 |
| 长期 | 复购原因、转介绍、内容寿命 | 把依赖当忠诚 |

## 二、漏斗诊断

- 有曝光、留存低：入口或受众相关性有问题；
- 留存高、主页访问低：主张有趣但身份和下一步不清；
- 主页访问高、私信低：定位、证据或产品说明不足；
- 私信高、成交低：适配、价格、信任或产品价值不清；
- 成交高、退款／疲劳高：承诺、产品范围或交付系统有问题；
- 复购高但问题重复：检查是否在制造依赖。

## 三、实验设计

~~~
假设：
目标对象：
内容任务：
保持不变：
只改变：
发布数量／周期：
主要指标：
护栏指标：
继续条件：
停止条件：
~~~

护栏指标包括不适配私信、争议、举报、取关、退款、制作工时和交付负担。样本小、平台波动和发布时间差异都可能影响结果。

## 四、定性反馈

比“好喜欢”更有用的反馈：

- 用户怎样复述主张；
- 哪一步被误解；
- 哪个词让用户停下；
- 用户说正在处理什么现实问题；
- 看完采取了什么行动；
- 为什么没有采取下一步。

评论区不是代表性调查，但能生成下一轮假设。

## 五、月度内容复盘

只回答：

1. 哪些内容持续吸引目标对象；
2. 哪些内容建立理解和信任；
3. 哪些内容带来可服务的需求；
4. 哪些内容带来错误期待或过高成本；
5. 哪个母题应该继续深挖；
6. 下月只改变哪个变量。
