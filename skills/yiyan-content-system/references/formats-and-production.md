# 形式与生产系统

## 一、形式匹配

| 任务 | 优先形式 | 原因 |
|---|---|---|
| 冲突与观点 | 短视频、短文 | 快速建立主张和人格 |
| 步骤、清单、对比 | 图文、屏幕录制 | 便于保存与复看 |
| 长逻辑和理论 | 长文、长视频、播客 | 保留论证和边界 |
| 示范一项技能 | 屏幕／桌面／现场演示 | 可观察过程 |
| 案例复盘 | 图文＋视频或长文 | 同时承载数据和叙事 |
| 实时答疑与需求研究 | 直播 | 获得即时问题与异议 |
| 系统教学 | 课程或系列内容 | 支持练习、反馈和顺序 |

形式选择还要考虑创作者的声音、镜头能力、制作时间、隐私和无障碍需求。

## 二、六段脚本

1. **冲突／问题**：让目标对象认出与自己有关；
2. **场景**：具体到一次行为、选择或后果；
3. **主张**：给出这一条要建立的判断；
4. **方法**：展示 2～4 个判断动作；
5. **证据／例子**：案例、数据、演示、对比或来源；
6. **邀请**：只保留一个下一步。

钩子可以压缩信息，不能承诺正文无法兑现的结果。

## 三、不露脸系统

可使用：

- 课件配音；
- 屏幕录制；
- 桌面手部；
- 物件与场景叙事；
- 图文转视频；
- 声音＋固定视觉；
- 字幕与信息图。

固定字体、颜色、声音、开场逻辑和证据标准，比频繁更换滤镜更能形成识别。涉及隐私时注意屏幕通知、文件名、地理信息和客户资料。

## 四、内容资产化

每条内容保存：

~~~
内容 ID：
母题：
目标任务：
主张：
原始证据：
来源：
脚本／正文：
已发布平台与日期：
表现：
有效反馈：
可复用到：
需要更新的事实：
~~~

资产化不是重复发同一条。应根据平台和用户阶段重新组织入口、长度和 CTA，同时保持事实与主张一致。

## 五、最小生产节奏

适合个人经营者的起点：

1. 每周选一个母题；
2. 做一次扎实研究；
3. 产出一条主内容；
4. 拆成 2～4 个轻内容；
5. 统一记录问题和反馈；
6. 周末只决定继续、停止和下周唯一实验。

具体频率按产能调整，不把高频发布当成道德要求。
