# 一炎自媒体与内容系统

## 每条内容先回答

目标对象是谁？他处于什么具体场景？这一条只讲哪一个主张？依据是什么？看完能做哪个最小动作？唯一 CTA 是什么？

## 五类栏目

1. 认知与观点：让用户发现问题；
2. 方法拆解：展示从问题到判断的过程；
3. 案例与复盘：匿名、具体、有限地证明方法；
4. 工作台与人格：展示取舍、准备、记录和标准；
5. 产品与邀请：说明适合谁、怎样交付、带走什么。

## 六页短视频

钩子 → 场景 → 主张 → 方法 → 例子 → 邀请。每条只解决一个判断，正文要给证据和限制。可用课件配音、桌面手部、屏幕录制、物件叙事或纯字幕，不露脸不是内容价值的替代品。

## 数据复盘

记录制作工时、完播／阅读、收藏、主页访问、有效私信、适配预约、成交、履约、退款／投诉和有效时薪。播放量只代表触达，不代表商业结果：私信多不成交查适配和产品，成交多但交付失控先改范围和流程。

## 边界

不伪造专业资历、客户案例、收入截图或第三方背书；不使用恐惧、神秘权威、虚假稀缺和绝对结果。涉及健康、心理、法律、投资、宗教或平台规则时，明确边界并核对可靠来源。
