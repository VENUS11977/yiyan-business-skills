# 问题建模与安全

## 一、非诊断性问题建模

~~~
当前问题：
具体触发：
可观察事实：
自动解释：
情绪与身体反应：
采取／回避的行为：
短期功能：
长期代价：
个人优势与已有支持：
环境和关系因素：
当前价值与目标：
暂定维持循环：
替代解释：
低风险实验：
复评日期：
~~~

“维持循环”描述过程，不代表责怪用户。某个应对曾经可能很有用，只是在当前条件下代价变高。

## 二、事实、解释、预测、愿望、价值

| 层次 | 问题 |
|---|---|
| 事实 | 录音或第三方能观察到什么 |
| 解释 | 我怎样理解这些事实 |
| 预测 | 我认为接下来会发生什么 |
| 愿望 | 我希望什么发生 |
| 价值 | 我想以怎样的方式行动 |
| 行动 | 现在能做的下一步 |

这些层次都重要，不能用“事实”羞辱感受，也不能把强烈感受当成外部事实。

## 三、行为实验

~~~
当前解释：
预测：
替代解释：
最小且安全的行动：
观察什么：
不做什么：
停止条件：
结果：
更新后的理解：
~~~

实验不是证明用户错了。它用于获得新信息。涉及人身、法律、健康、财务或关系暴力风险时，不能自行实验。

## 四、安全升级

出现以下信号时，停止一般心理教育并转向现实安全：

- 自伤或伤人想法、计划、准备或近期行为；
- 无法保证自己或他人安全；
- 严重混乱、幻觉、妄想或与现实明显失联；
- 无法维持基本饮食、睡眠、卫生或照顾；
- 家暴、胁迫、跟踪和现实威胁；
- 药物、酒精或其他物质导致急性风险；
- 需要立即医疗处理的身体症状。

响应原则：

1. 直接而平静地关注安全；
2. 鼓励联系当地急救、危机服务或医疗机构；
3. 鼓励联系可信赖的现实支持者并避免独处；
4. 询问所在地后只提供可核实的当前资源；
5. 不承诺保密，不开展在线诊断或创伤处理；
6. 若工具无法联系外部资源，明确限制并让用户本人或身边人立即行动。

## 五、何时建议常规专业支持

- 困扰持续数周并明显影响工作、关系、睡眠或饮食；
- 反复发作或不断加重；
- 用户想确认疾病、药物或正式治疗；
- 自助实验无效或使情况更糟；
- 复杂创伤、进食问题、物质使用或高冲突关系；
- 用户希望获得稳定、保密、持续的专业关系。

建议联系合格心理咨询／治疗专业人员或医生时，说明这是能力边界，不把求助说成失败。
