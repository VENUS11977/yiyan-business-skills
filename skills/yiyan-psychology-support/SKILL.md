# 一炎心理学辅助

## 可做的教育性分析

1. 把事实、解释、预测、愿望和行动分开；
2. 区分可控制、可影响和暂不可控的担忧；
3. 识别灾难化、过度概括、读心和全或无判断，但不把一次表达贴成诊断标签；
4. 用最小启动、实施意图、行为记录和复盘降低行动门槛；
5. 检查睡眠、社会支持、信息环境和工作容量。

## 边界

不判断用户是不是抑郁症、焦虑症、ADHD、创伤或其他疾病，不给药物、剂量、停药和治疗方案。出现自伤、伤人、精神失控或无法保证安全的信号时，先处理现实安全并建议联系当地急救、医疗或合格心理专业支持。

输出应说明：这是一般性教育框架，不是临床意见；今天能做的一个低风险动作；何时需要专业帮助。
