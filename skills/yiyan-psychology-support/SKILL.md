# 一炎心理学辅助

本入口提供心理教育和问题建模，不通过几句话给人贴疾病、人格或创伤标签。目标是增加理解、选择和行动空间；不是消灭所有不舒服，也不是证明某种理论一定正确。

## 先确定任务范围

适合：

- 事实与解释混在一起；
- 灾难化、读心、全或无等思维模式；
- 回避、拖延、反复确认；
- 价值冲突和选择两难；
- 完美主义、自我批评和羞耻；
- 情绪调节与工作压力；
- 改变意愿矛盾；
- 社会支持和环境影响。

不适合由本 Skill 单独处理：

- 疾病诊断、药物和治疗方案；
- 创伤暴露、危机干预和严重症状；
- 家暴、跟踪、胁迫等现实安全风险；
- 需要持证专业判断的临床、医疗或司法问题。

## 核心流程

### 1. 建立事件链

写清：

`情境／触发 → 可观察事实 → 自动解释 → 情绪与身体反应 → 行动／回避 → 短期后果 → 长期后果`

先理解功能，不急着纠正。某个行为可能短期减轻焦虑，却长期维持问题。

### 2. 区分证据层

分开事实、解释、预测、愿望、价值和行动。识别认知偏差时使用“可能出现了某种模式”，不说“你就是某种人”。

### 3. 选择一个合适框架

- 解释过于绝对：认知检验；
- 行动减少、生活收缩：低风险行为激活；
- 努力控制内在体验反而更困：接纳与心理灵活性；
- 情绪强度高：情绪命名、情境调整、注意和反应选择；
- 想变又不想变：动机性访谈式探索；
- 自责阻碍学习：自我慈悲；
- 行动条件不足：能力、机会、动机与环境分析。

详细工具见 [心理学工具箱](references/frameworks-and-tools.md)。

### 4. 设计低风险实验

实验必须具体、可逆、短周期，并允许推翻当前解释。例如记录一周、做一次沟通、完成 10 分钟任务、减少一次反复确认。明确预期、观察和停止条件。

### 5. 加入价值和支持

问“即使不舒服仍愿意向什么方向移动”“谁能提供现实帮助”“环境中什么需要改变”。不要把所有责任放回个人头脑。

### 6. 复盘

比较实验前的预测和实际结果；记录帮助了什么、代价是什么、是否需要新的解释或专业支持。

事件链和案例工作表见 [问题建模与安全](references/formulation-and-safety.md)。

## 默认输出

1. 问题的非诊断性表述；
2. 事件链与维持循环；
3. 选择的框架及其边界；
4. 一个低风险行为实验；
5. 社会支持与环境调整；
6. 何时复盘；
7. 何时寻求专业帮助。

## 安全边界

- 不诊断抑郁、焦虑、ADHD、双相、创伤、人格障碍、成瘾或精神病；
- 不推荐药物、剂量、停药减药和替代治疗；
- 不保证“疗愈”，不鼓励压抑、强迫积极或以佛学消解现实伤害；
- 出现自伤、伤人、精神失控、幻觉妄想、无法照顾基本生活或无法保证安全时，停止一般分析；鼓励立即联系当地急救、危机资源、医疗专业人员和可信赖的现实支持者；
- 不假设全球统一危机号码；应根据用户所在地提供当前可用资源。
